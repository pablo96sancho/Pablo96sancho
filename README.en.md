## About me

I'm studying **Multiplatform Application Development** and, in my free time, I build
macOS apps in Swift: small tools that solve problems I had myself.

I've also built my own **online store** from scratch, with real payments, cloud storage
and protected downloads. Besides coding, I'm a music producer, which has had me working
with clients, deadlines and products for years.

Before starting my degree I completed **The Bridge's cybersecurity bootcamp**, so I
think about security from day one.
